# AI支援（D-089 / D-098）

Mac・iOSの「AI支援」から校正・感想と、会話形式のアドバイスを使う。APIキー・送信先・モデルは端末設定、会話・共通指示・作品別指示は本文と別の保存／同期経路で保持する。

## 会話と編集

「アドバイス」は参照許可の確認を挟まず、そのまま相談を入力して送信する。会話は最初の明示送信時に作成し、画面を開くだけでは作成・送信しない。各送信で「相談だけ」「選択中の話に追記」「選択中の話を編集」「プロット」「登場人物」「設定・資料」「作品全体」を選ぶ。既定値は相談だけで、編集許可はその依頼の終了時に閉じる。

「送る範囲」で章・話をチェックし、今回参照する本文を選ぶ。「現在の話だけ」で戻せる。選択外の話は本文を送らず、章・話の構成、人物・プロット・設定、会話履歴は引き続き参照する。すべて解除した場合は本文を送らずに相談できる。本文の選択は編集許可とは別で、範囲を変えても過去の会話履歴は消さない。

応答を待つ間も執筆できる。AIが変える箇所を手で直した場合は反映せず、回答と変更案を記録に残す。無関係な編集は維持する。文字変換中は最大15秒だけ確定を待ち、作品やアカウントが変わった場合は止める。現在の本文への反映は通常のUndoに1回分として登録し、話の切替後やアプリ再起動後は「変更履歴」から依頼単位で取り消す。同じ対象がその後に変わっていれば取り消しも拒否する。

会話の直近30発言と作品情報を次の送信に使い、保存済みの会話を削らない。選択した本文・構成・設定が送信上限を超える場合は、送信前に範囲を減らすよう案内し、選択した本文を黙って省略しない。生成に必要な型のテンプレートを付け、形式・ID・参照・範囲を検証してから反映する。アプリ終了などで中断しても、自動再送・自動再適用をしない。

## 指示と保存

「指示」で用途別の共通設定と作品別の追加指示を編集する。次の依頼から共通指示＋作品別指示を使い、当時の実効指示を依頼記録に残す。同時変更が競合した場合は片方を消さず、候補を選んで保存し直す。

共通指示は認証アカウント単位、作品の会話・指示は同期を有効にしてサーバーが受領済みの作品だけ同期する。未同期作品では端末に保存する。前面で開いている間は約10秒ごとにAI記録の同期を試す。原稿のローカル保存はこの通信を待たない。

`NovelWritingSupport`が記録と範囲付き編集の検証、`NovelWritingStore`が独立SQLite・送信待ち・変更記録を担当する。Mac/iOSのadapterがEditorKitと保存の境界を受け持つ。wire・保管・削除・復元の詳細は[AI記録の契約](sync/v2/assistant.md)。日次backupと作品の1年保管、account削除にもAI記録を含む。復元した記録の編集権限は継承しない。

## 校正・感想

校正は現在の1話、感想はチェックした話を対象に、固定した全文をpreviewしてから明示送信する。編集中の話が対象に含まれる場合は確定済み本文を使い、変換中は送らない。Mac・iOSとも、同じ本文・作品session・話・accountを照合してEditorKitの正規編集として適用し、native Undoで戻せる。

校正による追加・変更箇所は黄色で示し、自動保存では消さず、明示保存のcheckpoint成功後に消す。iOSでは「今すぐ同期」のローカル保存成功時に消し、通信成功は条件にしない。削除文字には色を付けない。色は表示のみで本文bytes・Undoを変えない。未完了の応答は採用しない。

色付けは変更のない行を除いてから文字単位で比較する。修正同士が離れていても、間の変更のない本文をまとめて着色しない。長い一段落、複数箇所の変更・削除、絵文字のUTF-16位置、実エディターでのUndo・Redo・色の解除を回帰テストで確認する。

感想と以前保存したアドバイスは、左の「感想・アドバイス」から引き続き読める。新しい感想は作品の添付形式で保存・同期する。[保存形式](sync/v2/assistant-feedback.md)。新しいチャットは独立したAI記録へ保存する。

## Macから外部AIを使う

AIパネルの「外部AI」でクライアント名を登録し、接続設定をコピーする。Macアプリを開いている間だけ、現在の作品をMCPから読み書きできる。資格情報はクライアントごとの端末限定Keychainに置き、解除すると待機中の操作も止める。

公開する操作は`read_work`・`edit_work`・`undo_edit`。本文、章・話、人物、プロット、伏線、メモ、設定ノート、添付資料を扱う。添付の編集は1件300 KB以内。作品自体の削除、アカウント、APIキー、アプリ設定、任意のファイルやコマンド実行は公開しない。

初回登録した接続を信頼し、外部AIが申告した依頼範囲を機械的に制限する。自然言語の依頼を正しく解釈したかまではアプリで判定できないという採択済みの方式で、誤編集には変更記録と取り消しを使う。同じ依頼IDは再適用せず、再送には記録済みの状態を返す。

## 通信と検証の境界

HTTPSのResponsesまたはChat Completionsを使う。既存の用途別モデル・API設定を引き継ぎ、キーは明示送信時にKeychainから読む。キー・MCP資格情報・接続設定を作品や同期DB、ログへ書かない。ephemeral URLSession、cookie/cacheなし、redirect拒否、timeoutとpayload上限、`store:false`を維持する。提供元の保存・料金方針はそのサービスに従う。

合成データで記録、範囲、同時編集、Undo、IME待ち、再送、復元、Swift/Rust間の日時互換を検証する。Test compositionは実HTTP・Keychain・MCP外部接続を拒否する。実APIの課金送信と私的原稿の送信は開発試験に使わない。署名済みアプリ、実端末の二台同期、実API接続はそれぞれ独立した受入として記録する。
