# 作品を取り出す手順

## アプリが使える場合

作品一覧の「復元」を開き、作品を選ぶ。サーバーの日時を選ぶと、その時点を別作品として復元する。削除した作品も削除日から1年間選べる。「この端末の削除時の原稿」は最後に端末へ保存した内容で、サーバーに未送信の変更を含む。こちらは新しいローカル作品へ取り出し、勝手に同期しない。

復元後は作品一覧から新しい作品を開き、本文・人物・プロット・ノート・添付を確認する。元の作品は残る。通信が切れて成功を確認できなかったら、同じ日時を選び直す。同じ操作を再確認するため、作品が二重に増えない。

Macの書き出し形式「本文と資料をまとめる（.zip）」、iPhone/iPadの「本文と資料を書き出す（ZIP）」では、本文.md、資料.md、作品データ.json、元の添付と資料ファイルを出力する。ZIPを展開すればFUMINIWA以外でも読める。

## アプリが起動できない場合

アプリを終了し、端末のSnapshot Sync v2保存フォルダを保全する。`snapshot-sync-v2.sqlite`だけをFinderでコピーするとWAL内の最新保存が欠けることがあるため、フォルダ全体をコピーするか、以下の読み取り専用救出ツールを使う。正しい保存場所は起動構成の`localRoot`で確認する。別の空DBを作って上書きしない。

```sh
python3 Scripts/export-local-recovery.py "/保存フォルダ/snapshot-sync-v2.sqlite" "/救出先/新しいフォルダ"
```

元DBは読み取り専用で開く。SQLite backup APIでWALを含む一貫した作業コピーを作り、作品ごとの現在のsnapshot/objectのSHA-256を検証して書き出す。出力先は新規フォルダに限り、元原稿・DB・鍵は変更しない。同期済みかどうかや削除markerにかかわらず、端末に残る全作品の現在の保存を取り出す。エラー時は「復旧結果.txt」が作られず、途中までの出力を復旧完了として扱わない。

暗号化した自宅サーバーの日次backupからのDB復旧は[運用手順](ACCOUNT_RETENTION_OPERATIONS.md)に従う。通常はDB全体を本番へ巻き戻さず隔離して復元し、必要作品を新しい作品として取り出す。アカウント削除確定済みのデータを再公開しない。外部backupは設けておらず、自宅サーバー全損は保証対象外。
