# 利用者の方針と判断待ち

| 項目 | 現在の方針 |
| --- | --- |
| 検証 | 検証なし／軽い／中ぐらい／重たいを変更の影響で選ぶ。マージだけを理由に増やさない |
| 保存 | 端末SQLiteを正本とし、通常保存からコピーを自動生成しない |
| 同期用コピー | 明示操作で作る。原本と既存コピーを勝手に削除しない |
| 認証・回復 | Appleログインのみ。メール・別provider・運営本人確認による回復は作らない |
| アカウント削除 | 明示予約から30日（720時間）の取消猶予。Apple通知だけでは予約しない |
| backup | 毎日暗号化取得し、作成から1暦年保持。アカウント回復サービスの約束にしない |
| インフラ | Cloudflare有料枠が必要になる処理は、可能な限り自宅サーバー`192.168.11.5`で行う |
| 添付 | 250 MiB契約を維持し、8 MiB単位で送信する |
| Windows | Windows 11、MSI等のインストーラー。具体的な実装ツールは要件内で選ぶ |
| macOS配置 | AIは右、執筆時のプロットカードは下。伏線はプロット編集画面の右下に置く |
| AI（現行） | 校正は現在の1話、感想・アドバイスは選択した話。全文preview後に明示送信 |
| AI（次期方針） | アドバイスのチャット化、プロンプト同期、プロット・人物の生成修正、続きの本文生成、MCPを検討。指定範囲内はAIの直接編集を許可。送信許可・同期単位・MCP配置は未確定 |
| AI保存 | 感想・アドバイスの保存・削除は作品同期に含める。APIキー・接続設定は端末限定 |
| 原稿コピー | 指定範囲のplain text。AIプロンプトを付けない |
| 自動保存 | 連続入力中のdebounce期限変更は採用しない |
| 名称 | `NovelSyncV2`、`SyncServerV2`、通信・schemaのv2表記を維持する |
| 開発補助 | XcodeBuildMCPをAppleの起動・画面確認に使う。既存の検証段階・XcodeGenは維持する |
| コード・文書 | 現行実装を中心に保ち、廃止実装と過去の全文はGit履歴へ集約する |

機能を利用可能にするための必要なデプロイは、対象・backup・反映後の確認を行って進める。GitHubへのpush／PR／mergeと実データ削除は、その操作の依頼範囲で行う。既存の許可を取り直さない。

## 判断待ち

2026-09-26の対話で、外部バックアップを設けない方針を採択した。自宅サーバー全損でそこにしかない原稿・履歴が失われることは許容する。退避先・鍵の別媒体保管は判断待ちから外す。

自分の執筆と原稿保全を優先し、一般公開・収益化・Windows対応には期限を設けない。同期を有効にした作品のみを対象に、通常の作品削除後1年保持・別作品復元・7日間の詳細履歴と以後の日単位1年保持・小さな未同期通知を次期要件とする。アカウント削除の30日猶予は変更しない。

合意条件、現行との差分、2026-09-26の隔離DB復元結果、AIの残る判断は[原稿保全・AI計画](PROTECTION_AI_PLAN.md)。この方針採択は実装完了や旧削除動作の変更を意味しない。

予約・取消の画面、通知route差分、CA export修正、Windowsの要件内toolchain選定は実装上の残件であり、決定済みの30日・1年・Apple-only・Windows 11を再承認する必要はない。公開対象や料金、既定UI、原稿保全方針を変える場合は、その変更に必要な判断だけを提示する。

現行実装は[CODE_HEALTH](CODE_HEALTH.md)、採択済みの設計は[DECISIONS](DECISIONS.md)。
