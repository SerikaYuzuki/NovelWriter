# 利用者が決めた方針

| 項目 | 現在の方針 |
| --- | --- |
| 検証 | 検証なし／軽い／中ぐらい／重たいを変更の影響で選ぶ。マージだけを理由に増やさない |
| 保存 | 端末SQLiteを正本とし、通常保存からコピーを自動生成しない |
| 同期用コピー | 明示操作で作る。原本と既存コピーを勝手に削除しない |
| 認証・回復 | Appleログインのみ。メール・別provider・運営本人確認による回復は作らない |
| アカウント削除 | 明示予約から30日（720時間）の取消猶予。Apple通知だけでは予約しない |
| backup | 毎日暗号化取得し、作成から1暦年保持。アカウント回復サービスの約束にしない |
| インフラ | Cloudflare有料枠が必要になる処理は、可能な限り自宅サーバー`192.168.11.5`で行う |
| 添付 | 250 MiB契約を維持し、8 MiB単位で送信する |
| Windows | Windows 11、MSI等のインストーラー。具体的な実装ツールは要件内で選ぶ |
| macOS配置 | AIは右、執筆時のプロットカードは下。伏線はプロット編集画面の右下に置く |
| AI | 校正は現在の1話、感想・アドバイスは選択した話。全文preview後に明示送信 |
| AI保存 | 感想・アドバイスの保存・削除は作品同期に含める。APIキー・接続設定は端末限定 |
| 原稿コピー | 指定範囲のplain text。AIプロンプトを付けない |
| 自動保存 | 連続入力中のdebounce期限変更は採用しない |
| コード・文書 | 現行実装を中心に保ち、廃止実装と過去の全文はGit履歴へ集約する |

機能を利用可能にするための必要なデプロイは、対象・backup・反映後の確認を行って進める。GitHubへのpush／PR／mergeと実データ削除は、その操作の依頼範囲で行う。既存の許可を取り直さない。

利用者が決める必要がある残件は、別機器へのbackup・鍵の退避先。料金・添付上限・原稿保全の方針変更が必要になれば、具体的な影響を示す。現在の実装と未完了事項は[CODE_HEALTH](CODE_HEALTH.md)、詳細は[DECISIONS](DECISIONS.md)。
